# Trace — scriptwriting grounding bounce, 2026-09-05

**Category:** system-level (skill routing). Candidate, not promoted.
**Task shape:** format-led script request (Skeptic Test, two-person, real advisor) on a brand with a built idea bank and an approved-pending roadmap.
**Source:** `context-grounding-review` verdict on the first draft of the skeptic-plus-advisor script, 2026-09-05. Bounced.

## What was missed, one line each

1. **Idea bank not loaded before drafting.** The script re-invented a concept that three existing entries already held (`the-credential-that-speaks`, `you-can-decline-your-jobs-plan`, `the-verification-moment`), and so lost the E1 gate and a proven overlay line those entries carry. `SKILL.md` step 2 says load the idea bank first; the generator skipped it.
2. **1:1 adaptation claimed without the reference's full segment map.** The generator called it a six-beat 1:1 of `moms-63 3e` from transcript fragments in `source-pulls/ad-account.md`; the full map in `audits/2026-09/biweekly-iterations-report.md` showed a dropped 11-second opener and a dropped narrator close. The honest classification was format-led, anchored on the body.
3. **CPL attributed to the body arc when it belonged to the dropped opener.** The hook audit's own pattern read ("the variation is entirely in the first three seconds") was loaded and not applied.
4. **Unsourced micro-direction.** Four small gestures with no source ad, against `visual-vocabulary-method.md` "No invented direction."
5. **Staging mis-marked in-play.** Phone-on-speaker was marked in play citing phone-to-ear ads; the vocabulary records it as adjacent (Hendry).
6. **Two overstated account facts** ("only thing over 12% hold," "the only time a doctor was on screen") from writing the rationale from memory of the docs instead of re-checking them.
7. **Casting left blank** when the roadmap and creator-talent input both name the cast (advisor, late forties) for exactly this shot.

## Rule to infer (candidate)

Before drafting any script for a brand with an idea bank: open the bank's evaluation and grep the entries for the concept. If a matching entry exists, execute from it and carry its gates. And when claiming adaptation, load the fullest beat map the vault holds for the reference (the iterations report usually has it), not the first transcript fragment found.
