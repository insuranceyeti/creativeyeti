# Expert insights — Health For Moms

Where outside expert knowledge lands when someone hands Parker a source: a video, a transcript, a
tweet, a post, a newsletter, a podcast, an article, a report. Written by `/expert-signal-intake`.

This sits at the repo root rather than inside `parker-system/` because it is brand property, not
method. Parker loads it alongside `brand-lens.md` on creative-strategy work, so what the team
captures here keeps shaping the output long after the conversation that produced it.

## The three stages

- **`inbox/`** — raw captured sources, verbatim. Nothing generalized yet.
- **`curation/`** — the read on each source: what is genuinely new, what is already known, what
  contradicts something this brain believes.
- **`context-update-candidates/`** — exact proposed changes to standing docs, for a human to
  approve, modify, or deny. Nothing is applied without that approval.
